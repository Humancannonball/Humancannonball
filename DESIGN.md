# Profile maintenance

The profile uses an original static SVG banner, one local product screenshot, and standard GitHub Markdown. No live badge services or build workflow are required.

Design references reviewed on 2026-09-13:

- [Awesome GitHub Profile README](https://github.com/abhisheknaiidu/awesome-github-profile-readme): examples of minimal profiles and project presentation.
- [DenverCoder1](https://github.com/DenverCoder1/DenverCoder1): visual header and direct navigation links.

These informed the structure; no template code or artwork was copied.

`assets/amberdetect-preview.png` comes from the public AmberDetect repository. Its image links to the live application because GitHub's Markdown renderer does not embed iframes. Update the screenshot when the public interface changes.

Technical background was condensed from the owner's resume. Keep this a project portfolio: omit the full work history, personal contact details, and internal employer metrics.
