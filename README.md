## Selected Work

### [AmberDetect](https://github.com/Humancannonball/AmberDetect)

AI-assisted moderation and audience-signal dashboard for YouTube creators. The system retrieves comments, classifies them into review categories, streams progress to the dashboard, and keeps moderation decisions in the creator's hands.

Core stack: Next.js, Node.js, AWS Lambda, DynamoDB, YouTube Data API, Google OAuth, OpenAI structured outputs, TypeScript, and benchmark/evaluation scripts.
